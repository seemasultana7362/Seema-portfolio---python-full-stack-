# Portfolio Image Assets Folder (`/public/images/`)

Place your custom pictures in this folder. Any image you drop here with the corresponding filename will automatically appear on your live website!

## 📸 Profile Picture
- **Filename**: `profile.jpg` (or `profile.png` / `profile.webp`)
- **Location**: `public/images/profile.jpg`
- **Recommended Ratio**: Square (1:1), e.g., 800x800 px
- **Where it appears**: Hero section profile card on the home page
